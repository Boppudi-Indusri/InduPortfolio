# My Portfolio Website

A fully responsive and interactive personal portfolio website built using HTML and CSS only.

## Features

- Semantic structure
- Responsive design for all major devices
- Skills with progress bars
- Certificates and project cards
- Contact form and resume download
- Pure CSS animations

## Folder Structure

- `/images`: All icons and profile photos
- `/certificates`: Certification PDFs
- `/resume`: Resume file
